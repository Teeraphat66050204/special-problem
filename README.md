# Special Project Repository

This repository contains the foundation for a web application that stores,
extracts, and searches special-project documents.

## Planned Stack

- Backend: NestJS and TypeScript (`apps/api`)
- Frontend: SvelteKit (`apps/web`, planned for semester 2)
- OCR research: shared rendering and reproducible OCR benchmarking
  (`experiments/ocr-benchmark`)

## Current Scope

The current milestone only establishes the OCR benchmark structure and
methodology. Application frameworks, OCR libraries, and OCR runners have not
been installed or implemented yet.
